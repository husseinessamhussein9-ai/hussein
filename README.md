# نَغَم — فيديو من أغنيتك

موقع مجاني تمامًا: ارفع أغنية، والموقع يحلّل الإيقاع والمزاج ويولّد كليب سينمائي متزامن معاها، وبعدين تنزّله.

- من غير تسجيل
- من غير علامة مائية
- الأغنية متتتبعتش لأي سيرفر — كل حاجة بتتعمل في المتصفح

## التشغيل

افتح `index.html` من سيرفر محلي (مش من الملف مباشرة عشان المتصفح يمنع قراءة الملفات):

```bash
python3 -m http.server 8080
```

بعدين افتح `http://localhost:8080`

## الاستخدام

1. ارفع MP3 أو WAV أو M4A
2. اكتب اسم الأغنية والفنان
3. اختار الستايل والمقاس (يوتيوب / تيك توك / مربع)
4. اضغط تشغيل تتفرج على المعاينة
5. نزّل الفيديو

التصدير بيسجّل المشهد في الوقت الحقيقي، فلو اختارت الأغنية كلها هتستنى نفس مدتها.

أفضل متصفح: Chrome أو Edge.
