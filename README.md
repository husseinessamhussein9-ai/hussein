# نَغَم Studio — فيديو فاخر من أغنيتك

استوديو مجاني في المتصفح: ارفع أغنية، والمخرج الذكي يبني كليب سينمائي مع كلمات كاريوكي.

## الميزات

- تحليل إيقاع ومزاج ومقاطع الكورس
- مخرج AI يغيّر المشاهد مع الطاقة
- لصق الكلمات، أو استخراجها بـ Whisper على جهازك، أو جلبها بالاسم
- كاريوكي / سينمائي / حركي / أنيق
- موجة صوتية، اختصارات لوحة المفاتيح، حفظ إعدادات
- غلاف وخلفية خاصة، كروت بداية ونهاية
- 16:9 و 9:16 و 1:1 — 720p أو 1080p
- من غير تسجيل ومن غير علامة مائية

## التشغيل

```bash
python3 -m http.server 8080
```

افتح الموقع من كروم أو إيدج.

1. ارفع الأغنية
2. تبويب **الكلمات**: الصق الكلام أو اضغط استخراج
3. اضغط تشغيل (مسافة)
4. نزّل الفيديو

اختصارات: مسافة تشغيل · الأسهم تقديم · S حفظ الإعدادات
